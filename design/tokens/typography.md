# Typography tokens · Quant Lab

| Role | Stack | Size guidance |
| --- | --- | --- |
| UI (all) | `JetBrains Mono`, `Noto Sans SC`, `ui-monospace`, `monospace` | 11–13px body; KPI values 15–16px bold |
| Numeric | same + `font-variant-numeric: tabular-nums` | Align columns in KPI / tables |

Fonts loaded from Google Fonts CDN in [`apps/web/index.html`](../../apps/web/index.html). Default UI language is English; Chinese glyphs use Noto Sans SC fallback.
